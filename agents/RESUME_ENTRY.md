# Human2Robot resume entry

Status as of 2026-09-25, after the dynhand to human2robot rename and the
completion of C++ trajectory-optimization phases B through G.

## What exists now

- Python package `src/human2robot/` (renamed from dynhand; entry points are
  `human2robot-*`, env id `Human2Robot-AllegroPickup-v0`). Python phases
  0-2 and 6 done, 4/5 scaffolded with synthetic demos, 7/8 not started,
  10 partial. Details in `docs/HANDOFF.md`.
- C++20 library `cpp/` (h2r_traj): trajectory representation, linear and
  cubic Hermite interpolation, finite differences, moving-window smoothing,
  projection onto joint/velocity/acceleration limits, metrics, weighted
  cost (tracking, velocity, acceleration, jerk, collision, limits), and a
  seeded stochastic optimizer with projection. 57 GoogleTest cases pass.
- pybind11 module `h2r_cpp` (cp311) exposed through
  `src/human2robot/cpp_bindings/` and used by
  `src/human2robot/optimization/pipeline.py`.
- Experiment artifacts: `results/trajectory_optimization/report.json`
  (100 demos, 100/100 converged, max velocity down 65 percent, max jerk
  down 44 percent, smoothness cost down 93 percent, 6.1 s wall).
- Tests: 126 Python cases pass with 90.95 percent coverage; the C++ suite
  runs through ctest. MuJoCo open-loop replay of optimized demos is
  covered by `tests/python/test_mujoco_replay_optimized.py`.

## Toolchain notes (Windows machine)

- clang++ 22.1.6 targeting MSVC (BuildTools 14.50), Ninja via the project
  venv (`uv add ninja`), CMake 4.1.3. Exact configure command in
  `cpp/README.md`. Set `PYTHON_EXECUTABLE` to the venv python or the
  pybind11 module silently targets miniconda Python 3.13.
- GPU: RTX 5060 8GB, sm_120, torch cu128. CPU: 24 cores.
